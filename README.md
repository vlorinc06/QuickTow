# QuickTow

A QuickTow egy webalkalmazás, amely lehetővé teszi autómentők gyors keresését és vontatási kérelmek kezelését.

---

##  Fő funkciók

* Autómentők keresése térképen
* Vontatási kérelem létrehozása
* Állapotkövetés
* Értékelési rendszer

---

## Használt technológiák

* Frontend: Angular
* Backend: Laravel
* Adatbázis: MySQL

---

## Indítás

Backend:

php artisan migrate --seed
php artisan serve

Frontend:

npm install
ng serve

---

## Felhasználó típusok

* Normál felhasználó (kérés létrehozása)
* Autómentő (kérelmek fogadása)

---

## Leírás

A felhasználó kiválaszthat egy autómentőt, megadja az útvonalat, majd elküldi a kérelmet.
Az autómentő elfogadhatja vagy elutasíthatja, elfogadás után a folyamat követhető.
